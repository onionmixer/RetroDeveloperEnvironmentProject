# diskwork/emptydisk/macintosh

Empty / pre-formatted Macintosh disk image templates. These are starting
points for new Mac disk work — clone one, then add files via
`rdedisktool add --macbinary` (or `--apple-double`).

## Contents (regenerable)

| File | Geometry | Filesystem | Notes |
|------|----------|-----------|-------|
| `empty_hfs_1440.img` | 80 × 2 × 18 × 512 | HFS | 1.44 MB SuperDrive default |
| `empty_hfs_800.img`  | 80 × 2 × 10 × 512 | HFS | 800 K floppy (Mac Plus / SE 800K mode) |

Volume name is `Untitled` for both. Boot block scaffolds with `LK`
signature + halt-loop; volumes become bootable only when real `System`
+ `Finder` files are added.

## Regenerating

```bash
RDE=./RetroDeveloperEnvironmentDisktool/build/rdedisktool
$RDE create diskwork/emptydisk/macintosh/empty_hfs_1440.img -f mac_img --fs hfs -n "Untitled" --force
$RDE create diskwork/emptydisk/macintosh/empty_hfs_800.img  -f mac_img --fs hfs -n "Untitled" -g 80:2:10:512 --force
```

## Where to put non-empty disks

- Canonical bootable System disks → `diskwork/bootdisk/macintosh/`
  (`system_608_master.image` etc., gitignored — System 6.0.8 carries
  copyrighted Apple software)
- Per-example combined / derived disks → inside the example, e.g.
  `Examples/prototype_01_mac_finder/system_608_with_hello.img` (gitignored,
  regenerated by that example's `compile.sh disk`)
- Mac ROMs → `resource/Macintosh/rom/`
