prototype_01_AppleII_prodos

Purpose
- Apple II ProDOS port of prototype/01 core loop with 10x10 visible map.

Implemented (current)
- 100x100 room data generated from original JSON
- 10x10 camera viewport rendering
- Movement + wall collision
- Monster encounter (patrol/chase/return + collision message)
- Door/Stair transition prompt (1=yes, 0=no)
- Box interaction: effect -> item list (2-step)
- 3-line HUD below coordinate line (status/help/input hint)
- Help screen and quit prompt (1=yes, 0=no)

Build
1) cd ./Examples/prototype_01_AppleII_prodos
2) ./compile.sh all
3) Output: ./HELLO

Runtime Keys
- Move: W A S D (also I J K L)
- Help: H (W/S scroll, SPACE return, Q quit prompt)
- Quit: Q (1=yes, 0=no)
- Confirm: 1=yes, 0=no

Disk Insert Example (ProDOS)
- rdedisktool add <disk.po> ./HELLO HELLO --type B --addr 0x0803

Notes
- Room data is generated by tools/json_to_room_data.py from:
  /mnt/USERS/onion/DATA_ORIGN/Workspace/04_Game/prototype/01/data
- Viewport is fixed at 10x10 by design.
