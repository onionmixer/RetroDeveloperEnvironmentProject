# prototype_01_mac_finder

Minimal classic-Mac (System 6/7, 68K) Toolbox application: shows a modal
dialog with a single **Hello** button; clicking the button quits.

Built with **Retro68** (`m68k-apple-macos-gcc`), packaged as a Mac
application + raw HFS disk, and run inside **snow** alongside the trimmed
System 6.0.8 boot floppy.

## Build

Requires the Retro68 toolchain at `Library/Retro68-build/toolchain/`. If
absent, `compile.sh build` will tell you how to build it.

```bash
./compile.sh build      # cmake + make → build/Hello.{APPL,bin,dsk,ad,...}
./compile.sh disk       # rebuild ./system_608_with_hello.img (System 6.0.8 + Hello)
./compile.sh test       # inspect Hello.dsk via rdedisktool
./compile.sh all        # clean + build + disk + test
./compile.sh clean      # remove build/ and system_608_with_hello.img
```

The `disk` step clones `diskwork/bootdisk/macintosh/system_608.img` (the
trimmed System 6.0.8 master) and injects `build/Hello.bin` at the volume
root via `rdedisktool add --macbinary` (since rdedisktool `0ebb152`),
preserving both forks + Finder info (`APPL/????`). The bootdisk safe-add
verification runs automatically. Override the master with `MASTER_DISK=...`.

## Run in snow (single disk)

```bash
./run_snow_mac.sh
```

This per-example launcher delegates to the project-root `run_snow_mac.sh`
with `BOOT_DISK` pinned to the local `system_608_with_hello.img`. snow
boots Mac SE FDHD (default model) directly from the combined disk; double-
click **Hello** on the desktop, click the button to quit.

If you'd rather use the two-floppy layout (separate System disk + Retro68's
800K `Hello.dsk`), run from the project root with the trimmed System disk
as default:

```bash
EXTRA_DISKS=$PWD/Examples/prototype_01_mac_finder/build/Hello.dsk ./run_snow_mac.sh
```

(Note: snow's emulated Mac SE FDHD has only one floppy drive, so the
single-disk path above is what actually works end-to-end. The two-floppy
form is mainly for snapshotting/distribution of the app disk on its own.)

## Files

- `hello.c` — Toolbox init + `GetNewDialog` + `ModalDialog` loop
- `hello.r` — `'DLOG' (128)`, `'DITL' (128)` (one button, item id 1), `'SIZE' (-1)`
- `CMakeLists.txt` — Retro68 `add_application(Hello hello.c hello.r)`
- `compile.sh` — build / disk / clean / test / all
- `run_snow_mac.sh` — boots snow with the local combined image
- `system_608_with_hello.img` — derived (gitignored), regenerated by `compile.sh disk`
